# VisionInsight 1.0.0-rc.1

VisionInsight now provides a complete local workflow for reviewing recorded MP4 video: upload, processing status, metrics, moments, source-linked evidence, supported questions, and exports.

Quick Scan samples frames for a faster overview of people and basic objects. Event Pulse adds more detailed processing and annotated video. Before uploading, users can draw occupancy zones and crossing lines on a preview frame.

The service uses account ownership checks, persistent jobs, monthly usage reservations, cancellation, private artifact access, and retention. The billing integration includes Paddle checkout, the customer portal, and signed subscription callbacks. Paid checkout stays disabled until the seller, prices, domain, legal settings, and model licensing are ready.

## Verification

- 32 automated tests passed on Python 3.12.
- A real local browser completed registration, MP4 upload with a zone and line, processing, result review, and a question answered from the analysis data.
- The browser was checked at 320 and 375 pixel widths without horizontal overflow; the final console check reported no errors.
- The Docker image built successfully. Health, readiness, plan endpoints, and the dependency environment were checked inside the container.

These checks cover local development and the container. They do not cover a public deployment or real subscription purchases.

## Compatibility

The supported runtime is Python 3.12 with FFmpeg and FFprobe. Local development uses SQLite and an embedded worker. Compose uses PostgreSQL, a separate worker, and a shared analysis volume.

The analysis upload endpoint accepts the MP4 itself as the request body with `Content-Type: video/mp4`. Clients using the earlier multipart endpoint must update. The public recipes are `quick_scan` and `event_pulse`; optional regions use normalized coordinates in JSON-encoded `zones` and `lines` query parameters.

This candidate is intended for a fresh database. It does not include a migration path from an existing deployed schema.

## Remaining work before 1.0

The [release requirements](../RELEASE_GATE.md) cover model licensing, merchant approval, legal and contact information, SMTP, HTTPS hosting, backup restoration, security and load checks, and evaluation on representative labeled videos.

Default semantic retrieval, an evidence-constrained narrator, outbound customer callbacks, shared workspaces, and S3 storage are not delivered in this candidate. Their status is recorded in [the implementation table](../BLUEPRINT_STATUS.md). Tracking counts and moment quality remain estimates and should be checked against the footage.
